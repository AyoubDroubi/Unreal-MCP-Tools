Automation Test MCP Toolset

Epic MCP toolset that discovers, runs, stops and retrieves Unreal Automation Framework test results.

Why it helps

  • Codex can execute real Unreal tests
  • Structured JSON status/results
  • Works with existing automation tests
  • Supports filtered test batches

Codex / MCP role

Use as the standard post-change verification lane for editor/gameplay code and content tests.

Recommended workflow

  1. DiscoverTests once per session.
  2. ListTests using name/tag filters.
  3. RunTests or RunTestsByFilter.
  4. Poll GetTestStatus.
  5. Read GetTestResults and fix failures.
Watch out: Discovery is asynchronous and can take time; do not repeatedly rediscover unless tests changed.

Adoption decision

Must adopt. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
