Control Rig

In-engine rigging and procedural animation framework usable from Sequencer, Animation Blueprints and gameplay Blueprints.

Why it helps

  • Rig and adjust characters without round-tripping every change to a DCC
  • Procedural runtime controls
  • Sequencer integration
  • Full Body IK and modular rig workflows

Codex / MCP role

Useful target for future graph extraction/authoring support and for generating project-specific procedural rig utilities.

Recommended workflow

  1. Create a Control Rig from the skeletal mesh.
  2. Build a clean control hierarchy.
  3. Use it in Sequencer or Anim Blueprints where appropriate.
  4. Keep expensive procedural solves measured.
  5. Use Rewind/Animation Insights for runtime diagnosis.
Watch out: Separate rig authoring from gameplay state ownership; complex per-frame rigs can be costly.

Adoption decision

High for character work. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
