UnrealXistTools

Cross-platform PowerShell 7 helpers for Unreal project discovery, UAT, clean builds, project files, IDE launch and project refactors.

Why it helps

  • Wraps verbose Unreal command lines in repeatable scripts
  • Provides a practical clean-project command
  • Simplifies UAT build/cook/stage/run workflows
  • Works on Windows, macOS and Linux for many commands

Codex / MCP role

Reference implementation for shell automation. We can borrow patterns or call equivalent project-local scripts rather than make Codex reconstruct UAT flags every time.

Recommended workflow

  1. Install PowerShell 7.
  2. Clone UnrealXistTools and add it to PATH.
  3. Use UProject.ps1/UProjectFile.ps1 for discovery.
  4. Use UAT.ps1 for build-cook-stage flows and UProjectClean.ps1 for deliberate clean rebuilds.
Watch out: Review every cleanup/refactor command before running it on a working project; destructive switches should never be implicit.

Adoption decision

High for scripted workflows. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
