Blueprint Assist

Automatic Blueprint graph formatting plus keyboard-first node navigation and editing.

Why it helps

  • Cuts graph cleanup time
  • Consistent layout
  • Keyboard workflows
  • Reduces Blueprint spaghetti visually

Codex / MCP role

After Codex mutates a graph, a formatter integration could normalize node layout before review.

Recommended workflow

  1. Install the compatible plugin build.
  2. Share team settings through source control.
  3. Format after meaningful graph changes, not on every tiny operation.
  4. Use it as presentation/readability tooling, not architecture.
Watch out: Formatting cannot fix bad responsibilities or coupling. Keep architecture rules separate.

Adoption decision

High. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
