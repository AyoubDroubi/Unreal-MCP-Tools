BuildGraph

Epic's XML-based build orchestration layer on top of Unreal Automation Tool.

Why it helps

  • Build pipelines
  • Reusable build nodes
  • Parallelizable automation
  • Good for cook/package/test flows

Codex / MCP role

Codex can update BuildGraph definitions when project build/test requirements change.

Recommended workflow

  1. Keep BuildGraph scripts in source control.
  2. Separate build, test, cook and publish nodes.
  3. Parameterize platform/configuration.
  4. Run on dedicated build machines.
Watch out: Start simple; do not build an enterprise pipeline before the project needs it.

Adoption decision

High for build automation. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
