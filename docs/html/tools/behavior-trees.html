Behavior Trees & Blackboards

Event-driven decision trees backed by Blackboard state for scalable NPC behavior.

Why it helps

  • Visual AI decision flow
  • Reusable tasks/services/decorators
  • Blackboard-driven state
  • Built-in runtime debugging

Codex / MCP role

Codex can author Tasks/Services and review graph complexity; future MCP readers should expose tree nodes and Blackboard keys.

Recommended workflow

  1. Define a small Blackboard vocabulary.
  2. Build branches around high-level decisions.
  3. Keep Tasks focused and reusable.
  4. Use Services sparingly for periodic updates.
  5. Debug with the live Behavior Tree and Gameplay Debugger.
Watch out: Do not turn the Blackboard into a global dumping ground or run expensive Services every tick.
