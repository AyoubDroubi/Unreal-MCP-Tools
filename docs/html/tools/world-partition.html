World Partition

Grid-based automatic level streaming and large-world data management with OFPA, Data Layers and builder commandlets.

Why it helps

  • Automatic streaming
  • Single persistent world workflow
  • Works with OFPA
  • Automatable large-world processing

Codex / MCP role

Codex can maintain world-partition config and invoke builder commandlets, but should not bulk-resave a world without a clean branch and validation.

Recommended workflow

  1. Use for genuinely large worlds.
  2. Define streaming sources and data layers.
  3. Keep spatial loading flags intentional.
  4. Use builder commandlets for batch work.
  5. Profile streaming and memory on target hardware.
Watch out: Streaming grids and cross-cell references need architectural discipline; do not enable merely because the project uses UE5.

Adoption decision

Must adopt for large worlds. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
