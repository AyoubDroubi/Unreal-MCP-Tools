Multi-User Editing

Connects multiple Unreal Editor instances into a shared live editing session for real-time collaborative content work.

Why it helps

  • Multiple people can work together in the same world
  • Immediate transaction synchronization
  • Useful for review sessions, level dressing and collaborative iteration
  • Works on top of a defined source-control revision

Codex / MCP role

Mostly a human collaboration tool; Codex should understand that the live session does not replace source control and should avoid conflicting automated writes during a session.

Recommended workflow

  1. Make every participant sync the exact same project revision and engine version.
  2. Launch/join a short-lived Multi-User session on LAN/VPN.
  3. Collaborate live.
  4. At session end, persist and commit the agreed changes through normal source control.
Watch out: Epic explicitly positions Multi-User Editing as an addition to source control, not a replacement. Keep sessions short-lived and start from the same revision.

Adoption decision

Optional collaboration accelerator. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
