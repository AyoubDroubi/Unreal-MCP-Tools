Blueprint Console Commands

Makes it easy to expose Blueprint functions as developer console/cheat commands.

Why it helps

  • Fast gameplay debugging
  • Designer-friendly debug commands
  • Parameter autocomplete/help
  • Great for repeatable test setup

Codex / MCP role

Codex can call documented console commands during PIE debugging or generate new debug-only commands.

Recommended workflow

  1. Keep commands development-only.
  2. Group commands by system.
  3. Use commands to reproduce states quickly.
  4. Pair with automation tests where a scenario becomes stable.
Watch out: Never expose privileged/debug commands in shipping builds unintentionally.
