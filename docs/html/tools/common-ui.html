Common UI

Layered UI/input framework designed for complex game menus and multi-input navigation.

Why it helps

  • Controller-first navigation
  • Input routing
  • Activatable widget stacks
  • Cross-platform UI conventions

Codex / MCP role

Useful target architecture for menu-heavy games instead of ad-hoc widget creation/removal.

Recommended workflow

  1. Use Activatable Widgets for screens.
  2. Define UI layers/stacks.
  3. Integrate with the current UE 5.8 input model.
  4. Test keyboard/gamepad focus and back/accept behavior.
Watch out: Adopt for real navigation complexity; simple HUD-only games may not need it.

Adoption decision

High for controller/multiplatform UI. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
