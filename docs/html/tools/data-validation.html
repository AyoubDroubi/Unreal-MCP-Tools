Data Validation

Built-in validation framework for naming, budgets, dependency rules and project-specific asset constraints.

Why it helps

  • Catches bad assets on save/CI
  • Supports custom validators
  • Can validate dependencies
  • Ideal guardrail for AI-authored content

Codex / MCP role

After asset changes, run validators and repair failures before saving/committing.

Recommended workflow

  1. Define UEditorValidatorBase validators.
  2. Run validation on save and pre-submit.
  3. Use DataValidation commandlet in CI.
  4. Make validation failures block merges for critical rules.
Watch out: Keep validators deterministic and actionable; avoid noisy warnings that teams learn to ignore.

Adoption decision

Must adopt. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
