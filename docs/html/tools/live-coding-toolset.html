Live Coding MCP Toolset

Triggers Unreal Live Coding compilation and returns compiler diagnostics directly to MCP clients.

Why it helps

  • Fast C++ iteration
  • Compiler diagnostics returned to Codex
  • No manual toolbar interaction
  • Useful after small implementation changes

Codex / MCP role

Use for short compile/fix loops; pair with AutomationTestToolset after successful compilation.

Recommended workflow

  1. Enable Live Coding in Editor Preferences.
  2. Make a small C++ change.
  3. Call CompileLiveCoding.
  4. Inspect errors/warnings.
  5. Use a full editor rebuild when reflection/layout changes require it.
Watch out: Live Coding is not a substitute for a clean UBT/UHT rebuild after UCLASS/USTRUCT/UFUNCTION signature or module-level changes.

Adoption decision

High. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
