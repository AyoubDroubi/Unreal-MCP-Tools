Rewind Debugger

Records PIE gameplay and lets developers scrub backward through animation/gameplay traces to inspect what actually happened.

Why it helps

  • Time-travel style debugging
  • Animation Blueprint tracks
  • Variables/notifies/poses over time
  • Excellent for intermittent animation bugs

Codex / MCP role

Use trace findings as evidence when Codex edits animation logic instead of describing the bug from memory.

Recommended workflow

  1. Enable Animation Insights.
  2. Open Rewind Debugger.
  3. Record the failing gameplay segment.
  4. Pause and select the target object.
  5. Scrub tracks and inspect transitions/variables/poses.
Watch out: Enable Pose Watch/trace data intentionally; recording everything can add overhead and noise.

Adoption decision

Must adopt for animation-heavy games. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
