High for GPU memory

Render Resource Viewer

Snapshot of GPU memory allocations with resource size, flags, owner asset and filtering/search.

Why it helps

  • Find GPU memory hogs
  • Map allocations back to assets
  • Filter resident/streaming/RT/UAV resources
  • Fast content-budget review

Codex / MCP role

Future MCP export could rank resource owners automatically; for now use the viewer to supply measured asset targets.

Recommended workflow

  1. Open the viewer in the representative scene.
  2. Sort/filter by size/type.
  3. Browse large allocations to the owning asset.
  4. Optimize texture/mesh/LOD/resource configuration.
  5. Refresh and compare totals.
Watch out: It is a snapshot, not continuous tracing; refresh after state changes.

Adoption decision

High for GPU memory. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
