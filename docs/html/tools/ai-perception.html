High for AI

AI Perception

Sensory framework for sight, hearing, damage and custom stimuli that feeds AI awareness.

Why it helps

  • Unified sensory events
  • Works with Blueprint AI
  • Stimulus aging/configuration
  • Feeds StateTree/Behavior Tree decisions

Codex / MCP role

Codex should prefer perception events over ad-hoc distance checks on Tick for awareness systems.

Recommended workflow

  1. Add AI Perception to the controller.
  2. Configure only required senses.
  3. Register stimuli sources deliberately.
  4. React to perception update events.
  5. Store semantic state rather than re-querying perception everywhere.
Watch out: Tune sight/hearing ranges and affiliation filters; uncontrolled perception across many agents can be expensive.

Adoption decision

High for AI. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
