RenderDoc Integration

Single-frame GPU graphics capture integrated into Unreal for inspecting draw events, resources, pipeline state and shaders.

Why it helps

  • Deep rendering bug diagnosis
  • Frame-by-frame GPU inspection
  • Compare editor vs target captures
  • Free/open-source debugger

Codex / MCP role

Provide capture findings/event names to Codex for targeted rendering changes; do not ask it to optimize blindly from FPS alone.

Recommended workflow

  1. Install RenderDoc and enable/attach the Unreal plugin.
  2. Navigate to a reproducible frame.
  3. Capture one focused frame.
  4. Inspect expensive/incorrect passes and resources.
  5. Fix and capture the same scenario again.
Watch out: Full-resource/callstack captures can become very large and profiling itself adds overhead.

Adoption decision

High for rendering bugs. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
