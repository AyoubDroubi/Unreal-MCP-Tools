Editor Utility Widgets

Dockable UMG-based editor tools for project-specific buttons, dashboards and workflows.

Why it helps

  • Fast internal tooling
  • Blueprint-first
  • Great for designers
  • Can wrap repetitive project actions in a friendly UI

Codex / MCP role

Codex can create/support EUWs and later drive them through Slate Inspector when a direct tool call is not available.

Recommended workflow

  1. Create an Editor Utility Widget.
  2. Keep runtime and editor responsibilities separate.
  3. Expose project operations as buttons/forms.
  4. Use MCP or Slate Inspector to drive it when agent automation is useful.
Watch out: Do not hide important business logic only inside UI graphs; keep reusable logic in functions/subsystems/libraries.

Adoption decision

High. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
