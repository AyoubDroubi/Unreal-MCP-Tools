Gameplay Debugger

In-game overlay/debug categories for AI, navigation, behavior and custom gameplay state.

Why it helps

  • Live gameplay introspection
  • Custom categories
  • Great for AI/abilities
  • Faster than opening many editor panels

Codex / MCP role

Codex can add custom debugger categories for systems it builds so future debugging is easier.

Recommended workflow

  1. Enable useful built-in categories.
  2. Add project-specific categories for complex systems.
  3. Keep expensive collection code guarded.
  4. Use it during PIE/network debugging.
Watch out: Developer-only instrumentation should not become shipping runtime overhead.

Adoption decision

High. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
