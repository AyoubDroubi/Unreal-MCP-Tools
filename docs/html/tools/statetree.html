StateTree

Hierarchical state machine combining state-machine transitions with selector-style hierarchy.

Why it helps

  • Cleaner AI/state logic
  • Highly organized
  • Efficient
  • UE 5.8 improved authoring/compiler workflows

Codex / MCP role

Strong candidate for AI/NPC/interactable state systems; we should add dedicated read/write MCP support.

Recommended workflow

  1. Use for stateful decision logic.
  2. Keep tasks small.
  3. Use Evaluators for contextual data.
  4. Define explicit transitions.
  5. Avoid replacing simple booleans with a StateTree unnecessarily.
Watch out: StateTree is an architecture choice, not a universal replacement for Behavior Trees or simple state variables.

Adoption decision

High. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
