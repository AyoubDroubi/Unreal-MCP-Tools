MetaSounds

Sample-accurate DSP graph system for procedural, interactive and reusable audio sources.

Why it helps

  • Gameplay-driven sound
  • Sample-accurate timing
  • Reusable patches/presets
  • Procedural audio without external middleware for many cases

Codex / MCP role

Strong future MCP graph target; today Codex can help design parameter contracts and Builder API utilities.

Recommended workflow

  1. Create reusable Patches for shared DSP logic.
  2. Expose gameplay parameters.
  3. Use Sources/Presets for content variants.
  4. Profile render cost and voice counts.
  5. Keep gameplay events and audio rendering responsibilities separate.
Watch out: Audio graphs are DSP flow graphs, not Blueprint execution graphs; reason about real-time audio constraints.

Adoption decision

High for procedural/gameplay audio. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
