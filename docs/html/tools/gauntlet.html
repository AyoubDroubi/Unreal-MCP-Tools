Gauntlet Automation Framework

Launches and orchestrates editor, packaged game, server/client and platform test sessions.

Why it helps

  • Multiplayer sessions
  • Packaged-build verification
  • Device/platform testing
  • CI-friendly orchestration

Codex / MCP role

Codex can generate/update Gauntlet scripts and interpret failures after builds.

Recommended workflow

  1. Use RunUAT RunUnreal.
  2. Start with BootTest/EditorAutomation.
  3. Add server-client tests for networking.
  4. Collect artifacts/logs and fail CI on test failures.
Watch out: Functional tests alone cannot validate every multi-instance replication scenario; Gauntlet fills that gap.

Adoption decision

High for multiplayer/builds. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
