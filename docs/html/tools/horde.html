Horde

Epic infrastructure for build automation, remote execution, test automation, studio analytics and device farms.

Why it helps

  • CI/CD designed around Unreal workflows
  • Automation/Gauntlet test aggregation
  • Remote compute and build acceleration
  • Device allocation for mobile/console testing

Codex / MCP role

Codex can author BuildGraph/Horde config and inspect logs/results, but infrastructure changes should remain reviewed.

Recommended workflow

  1. Start only when project/team scale justifies dedicated infrastructure.
  2. Pilot Horde locally or on a small server.
  3. Connect agents and one build/test stream.
  4. Add auth, observability and resource pools before broader rollout.
Watch out: Horde is powerful and operationally heavier than a simple Azure/GitHub pipeline; do not adopt merely because it exists.

Adoption decision

Evaluate for teams. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
