Reference Viewer

Visualizes asset dependencies and referencers.

Why it helps

  • Find accidental hard references
  • Safe asset deletion/refactor
  • Dependency analysis
  • Essential for Blueprint load-chain review

Codex / MCP role

Our MCP project tools should expose the same dependency data in machine-readable form.

Recommended workflow

  1. Open around suspicious assets.
  2. Inspect both dependencies and referencers.
  3. Look for unexpected cross-feature references.
  4. Replace hard references with soft/data-driven relationships where appropriate.
Watch out: A dependency is not automatically a problem; optimize based on ownership/loading goals.

Adoption decision

Must adopt. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
