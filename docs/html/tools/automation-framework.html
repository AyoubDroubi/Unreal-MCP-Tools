Automation Test Framework

Unreal framework for unit, feature, smoke, content-stress and screenshot-comparison tests.

Why it helps

  • Regression protection
  • Headless/editor test execution
  • Content stress tests
  • Pairs directly with MCP AutomationTestToolset

Codex / MCP role

Codex should add or update tests with behavior changes, then execute them through the MCP toolset.

Recommended workflow

  1. Write fast smoke tests for core invariants.
  2. Add feature tests for systems.
  3. Add content stress tests for compile/load integrity.
  4. Run targeted tests during development and broader suites in CI.
Watch out: Do not mark slow tests as Smoke; keep test scope and runtime intentional.

Adoption decision

Must adopt. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
