Project Borealis UEGitPlugin

Refactored Unreal Git/LFS source-control provider with file locking and status-branch workflow improvements.

Why it helps

  • In-editor LFS locks
  • Git-aware asset workflow
  • Status branches
  • Production-oriented source-control improvements

Codex / MCP role

Useful if the team wants editor-native locks, but Codex can operate Git from CLI without requiring this plugin.

Recommended workflow

  1. Evaluate on a disposable UE 5.8 project first.
  2. Use HTTPS/Git Credential Manager.
  3. Adopt explicit .gitattributes.
  4. Keep CLI Git as the source-of-truth fallback.
Watch out: Open issues report compatibility/usability problems in newer UE versions; do not make it mandatory until tested on 5.8.

Adoption decision

Evaluate carefully. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
