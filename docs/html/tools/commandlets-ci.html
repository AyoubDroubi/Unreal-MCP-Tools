Unreal Commandlets in CI

Run validation, resave, cook and other editor operations headlessly through UnrealEditor-Cmd/commandlets.

Why it helps

  • Repeatable CI checks
  • No manual editor dependency
  • Asset validation at scale
  • Good merge gate

Codex / MCP role

Codex should produce CI commands alongside new validators/tools so every guardrail is automatable.

Recommended workflow

  1. Start with DataValidation commandlet.
  2. Add targeted project commandlets only for deterministic tasks.
  3. Fail CI on errors.
  4. Archive logs/reports.
Watch out: Headless/commandlet execution can differ from interactive editor paths; test both where relevant.

Adoption decision

Must adopt. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
