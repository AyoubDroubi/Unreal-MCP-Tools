Visual Logger

Time-based debugging tool that records gameplay events, text, locations, shapes and actor state.

Why it helps

  • Excellent AI/gameplay debugging
  • Spatial timeline
  • Works well for AI/navigation
  • Reconstructs what happened before a bug

Codex / MCP role

Codex can add targeted logging instrumentation and reason from exported logs/screenshots.

Recommended workflow

  1. Add focused UE_VLOG/Visual Logger data.
  2. Reproduce the issue.
  3. Inspect the timeline and spatial snapshots.
  4. Convert recurring manual diagnosis into automated assertions where possible.
Watch out: Log only meaningful state; excessive logging makes sessions hard to read.

Adoption decision

High. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
