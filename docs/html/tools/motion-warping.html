Motion Warping

Dynamically adjusts root motion to align animation windows with named world targets for mantling, melee, traversal and interactions.

Why it helps

  • Reuse animations across variable target positions
  • Better traversal alignment
  • Blueprint-friendly target updates
  • Avoids bespoke animations for every distance

Codex / MCP role

Codex can build consistent traversal/melee wrappers around warp targets instead of hard-coded teleport corrections.

Recommended workflow

  1. Enable Motion Warping.
  2. Add warp windows to montages.
  3. Add a Motion Warping component.
  4. Set/update named warp targets before playback.
  5. Test edge distances/rotations and network behavior.
Watch out: Beta feature; validate root-motion, prediction and multiplayer behavior on the exact target engine/build.

Adoption decision

High for contextual character actions. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
