Stat Commands & Console Profiling

Fast first-pass profiling using stat unit, stat game, stat gpu and related console diagnostics.

Why it helps

  • Zero-setup performance check
  • Quick CPU/GPU split
  • Useful during PIE
  • Guides when to open deeper Insights/GPU tools

Codex / MCP role

Codex can include performance console-command checklists in feature verification.

Recommended workflow

  1. Start with stat unit.
  2. Identify CPU vs GPU bound.
  3. Use targeted stat groups.
  4. Move to Unreal Insights/GPU profiling for deep diagnosis.
Watch out: Stats are snapshots/aggregates; use trace tools for deep causal analysis.

Adoption decision

High. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
