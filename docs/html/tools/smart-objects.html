Smart Objects

Reservation-based world interaction points that advertise activities to AI and players.

Why it helps

  • Decouples world interactions from specific NPC classes
  • Built-in reservation model
  • Reusable interaction definitions
  • Scales benches, doors, workstations and ambient behaviors

Codex / MCP role

Good architecture for systemic NPC/environment interactions instead of casts to every interactable class.

Recommended workflow

  1. Create a Smart Object definition.
  2. Expose slots and behavior definitions.
  3. Let agents query/reserve slots.
  4. Run the interaction behavior.
  5. Release the slot reliably on completion/cancel.
Watch out: Always handle cancellation and reservation release; orphaned claims create hard-to-debug AI stalls.

Adoption decision

High for interactive worlds. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
