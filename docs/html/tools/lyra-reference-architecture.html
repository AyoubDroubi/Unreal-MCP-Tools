High reference

Lyra Sample Game as Architecture Reference

Epic-maintained modular multiplayer sample demonstrating modern UE architecture including Game Features, GAS, Enhanced Input and scalable UI/gameplay patterns.

Why it helps

  • Real production-style examples instead of isolated snippets
  • Updated across major UE releases
  • Shows modular gameplay feature boundaries
  • Strong reference for multiplayer, abilities, inventory/equipment and UI architecture

Codex / MCP role

Codex can use Lyra as a pattern reference, but should not cargo-cult class names or architecture that the current game does not need.

Recommended workflow

  1. Install the Lyra version matching the target engine.
  2. Study one subsystem relevant to the current feature instead of copying the whole project.
  3. Document the pattern and why it fits your game.
  4. Implement a smaller project-specific version and validate complexity before expanding.
Watch out: Lyra is a learning/reference project, not a mandatory starter architecture; its complexity can be excessive for small games.

Adoption decision

High reference. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
