Environment Query System (EQS)

Scores generated locations or actors against tests so AI can choose cover, vantage points, pickups and other context-sensitive targets.

Why it helps

  • Data-driven spatial decisions
  • Pairs with Behavior Trees
  • Reusable generators/tests/contexts
  • Excellent for cover and positioning

Codex / MCP role

Useful for replacing hand-written nearest/cover search loops with an engine-native query asset.

Recommended workflow

  1. Create a focused query with a small candidate set.
  2. Define clear Contexts.
  3. Filter before scoring where possible.
  4. Run from Behavior Tree/AI logic.
  5. Use EQS debugging visualization and profile expensive tests.
Watch out: Large generators and expensive traces can become a hidden AI performance cost.

Adoption decision

High for spatial AI. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
