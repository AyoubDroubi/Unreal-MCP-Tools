Animation Insights

Unreal Insights extension for observing animation state, blend values and animation performance over recorded traces.

Why it helps

  • Animation timing/performance evidence
  • Blend/state visibility
  • Trace-based debugging
  • Pairs with Rewind Debugger

Codex / MCP role

Provide Codex with the measured track/state evidence before refactoring complex animation systems.

Recommended workflow

  1. Enable Animation Insights.
  2. Capture a representative PIE trace.
  3. Inspect animation/gameplay tracks.
  4. Find expensive or incorrect transitions.
  5. Re-capture after the fix.
Watch out: Profile representative gameplay; editor preview behavior may not match a packaged target exactly.

Adoption decision

High. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
