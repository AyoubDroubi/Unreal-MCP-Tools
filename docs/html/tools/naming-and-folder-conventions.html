Naming & Folder Conventions

Consistent asset prefixes, feature folders and ownership boundaries make large Unreal projects searchable and automatable.

Why it helps

  • Fast search
  • Safer bulk operations
  • Better validation
  • Codex can infer asset intent from names

Codex / MCP role

Naming conventions directly improve agent search precision and reduce accidental edits.

Recommended workflow

  1. Define prefixes for major asset types.
  2. Organize by feature/domain first.
  3. Avoid dumping assets into generic Misc folders.
  4. Enforce rules with Data Validation.
  5. Keep exceptions documented.
Watch out: Do not over-engineer names with excessive abbreviations; optimize for team comprehension and automation.

Adoption decision

Must adopt. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
