Unreal Build Accelerator (UBA)

Accelerates C++ compilation locally and, with Horde, can distribute build actions across remote machines.

Why it helps

  • Reduces iteration time on large C++ codebases
  • UBT integrates directly with UBA
  • Remote compilation can use otherwise idle machines
  • Especially useful once full editor builds become a productivity bottleneck

Codex / MCP role

Codex can inspect BuildConfiguration and build logs, but should not alter distributed-build infrastructure without an explicit task.

Recommended workflow

  1. Measure local clean/incremental build times first.
  2. Enable/tune UBA using UBT configuration.
  3. For remote acceleration, configure Horde agents and secure access.
  4. Track build reliability and speed before expanding the pool.
Watch out: Remote build support/platform details evolve by engine release; follow the exact UE 5.8 documentation and secure Horde authentication.

Adoption decision

High for C++ teams. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
