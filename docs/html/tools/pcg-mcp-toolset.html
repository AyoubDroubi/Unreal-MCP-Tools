PCG MCP Toolset

Epic toolset that lets an AI assistant build and modify PCG graphs using AICallable Unreal-native operations.

Why it helps

  • Creates and edits PCG graph nodes through Unreal APIs
  • Exposes graph structure and node schemas to agents
  • Avoids fragile UI-only PCG automation
  • Pairs naturally with the official Unreal MCP server

Codex / MCP role

Prefer this official toolset over adding duplicate PCG mutation methods to UnrealMCPTools.

Recommended workflow

  1. Enable PCG, PCGToolset, ToolsetRegistry and ModelContextProtocol.
  2. Ask the agent to inspect the graph before modification.
  3. Use native PCG tool calls to add nodes/subgraphs and parameters.
  4. Execute/validate the graph and inspect generated output before saving.
Watch out: The PCGToolset plugin is Experimental in UE 5.8. Pin the engine version and smoke-test tool contracts after upgrades.

Adoption decision

High for PCG projects. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
