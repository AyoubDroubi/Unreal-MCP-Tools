UE Node2Code

Exports Material and Niagara node graphs into compact text that is easier for AI agents to reason about.

Why it helps

  • Material graph readability
  • Niagara graph readability
  • Compact AI context
  • Useful when our native graph readers do not cover a graph type

Codex / MCP role

Useful read-only bridge for graph types beyond standard Blueprints.

Recommended workflow

  1. Install as a project plugin if compatible.
  2. Export the target graph.
  3. Feed compact text to Codex for analysis.
  4. Apply edits through Unreal-native APIs/editor tools.
Watch out: Prefer native structured readers once our MCP plugin supports the same graph type.
