Iris Replication System

Opt-in next-generation replication system designed for larger worlds/player counts with shared work, filtering and prioritization.

Why it helps

  • Replication scalability
  • Filtering/prioritization APIs
  • Parallel/shared replication work
  • Existing replicated properties/RPCs remain largely compatible

Codex / MCP role

Codex must not flip a project to Iris as a casual optimization; migration needs architecture review and measured validation.

Recommended workflow

  1. First build correct authoritative gameplay with normal replication.
  2. Profile real network/server limits.
  3. Evaluate Iris on a dedicated branch.
  4. Migrate unsupported/custom behaviors deliberately.
  5. Run multiplayer/Gauntlet/Network Insights regression suites.
Watch out: Epic marks Iris Experimental in UE 5.8; use caution for shipping and verify all project-specific replication behaviors.

Adoption decision

Evaluate for ambitious multiplayer. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
