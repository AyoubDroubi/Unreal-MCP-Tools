FlowGraph

Design-agnostic async node graph for game flow, quests, sequences and narrative scripting.

Why it helps

  • Avoids giant Level Blueprints
  • Async/latent by design
  • Reusable gameplay flow nodes
  • UE 5.8 release available

Codex / MCP role

Codex can help author custom flow nodes and inspect flow assets once we expose dedicated readers.

Recommended workflow

  1. Use when the game has substantial quest/narrative/event flow.
  2. Build project-specific Flow nodes.
  3. Keep low-level gameplay inside components/systems.
  4. Use FlowGraph to orchestrate, not own every gameplay detail.
Watch out: Adds a major architectural abstraction; adopt intentionally, not for tiny projects.

Adoption decision

High for quest/narrative flow. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
