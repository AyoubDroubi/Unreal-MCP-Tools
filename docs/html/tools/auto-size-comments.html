Auto Size Comments

Automatically keeps Blueprint comment boxes sized around their nodes and supports comment style presets.

Why it helps

  • Better graph documentation
  • Less manual comment-box maintenance
  • Readable large graphs
  • Works well with formatter workflows

Codex / MCP role

Codex can preserve comments and create meaningful graph sections; this plugin keeps the visual grouping tidy.

Recommended workflow

  1. Install into the project/engine plugin folder.
  2. Use consistent comment presets.
  3. Group logic by responsibility, not by arbitrary screen region.
  4. Review graph-specific compatibility.
Watch out: Some graph types have compatibility limitations; verify on the target UE version.

Adoption decision

High. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
