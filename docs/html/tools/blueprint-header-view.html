Blueprint Header View

Previews a Blueprint class or struct as C++-style declarations for variables, functions, components and dispatchers.

Why it helps

  • Makes Blueprint structure easier to understand from code-oriented workflows
  • Helps plan Blueprint-to-C++ migrations
  • Useful context for Codex before creating equivalent C++ types
  • Highlights class shape without manually reading every graph

Codex / MCP role

Use as supporting evidence when deciding whether a Blueprint should remain visual scripting or move behind a C++ API.

Recommended workflow

  1. Right-click a Blueprint class or struct.
  2. Choose Preview Equivalent C++ Header.
  3. Review variables, functions, components and event dispatchers.
  4. Use the preview as migration/design context; implement actual function logic manually in C++.
Watch out: This produces declarations, not a complete automatic Blueprint-to-C++ conversion.

Adoption decision

High. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
