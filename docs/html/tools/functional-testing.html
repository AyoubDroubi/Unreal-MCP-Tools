Functional Testing

Level/gameplay-oriented tests using Unreal's Functional Testing framework.

Why it helps

  • Tests real gameplay scenarios
  • Designer-visible test actors
  • Useful for Blueprint-heavy projects
  • Can validate PIE behavior

Codex / MCP role

Ideal for Blueprint features where pure C++ unit tests cannot capture the behavior.

Recommended workflow

  1. Create small deterministic test maps.
  2. Use FunctionalTest actors for scenarios.
  3. Keep setup isolated.
  4. Run through Automation Framework/Gauntlet as needed.
Watch out: Avoid giant all-purpose test maps; small targeted maps are easier to debug.

Adoption decision

High. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
