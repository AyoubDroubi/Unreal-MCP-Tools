Asset Manager & Primary Assets

Framework for explicit asset discovery, loading, bundles, auditing, cooking and chunking.

Why it helps

  • Scalable content loading
  • Primary Asset IDs
  • Soft-reference workflows
  • Packaging/chunk control

Codex / MCP role

Codex should prefer Asset Manager patterns for large inventories, abilities, maps, cosmetics and downloadable content.

Recommended workflow

  1. Define Primary Asset types.
  2. Use soft references for loadable content.
  3. Configure scan rules.
  4. Audit bundles/chunks.
  5. Load/unload through Asset Manager rather than ad-hoc global hard references.
Watch out: Do not introduce Asset Manager complexity for a tiny fixed-content prototype without need.

Adoption decision

High. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
