JetBrains Rider + UnrealLink / RiderLink

Deep Rider/Unreal Editor integration with Blueprint awareness, code navigation, game launch control and enhanced Unreal logs.

Why it helps

  • Find C++ usages from Blueprints
  • Navigate from C++ to the corresponding Blueprint in Unreal Editor
  • Run multiplayer configurations from the IDE
  • Use Unreal-aware inspections/refactors and filtered editor logs

Codex / MCP role

Useful companion IDE when Codex edits C++; it provides human verification of reflection usage and Blueprint/C++ coupling.

Recommended workflow

  1. Install/open the project in JetBrains Rider.
  2. Install RiderLink into the game or engine when prompted.
  3. Use Find Usages to include Blueprint-derived/reference information.
  4. Launch PIE/server/client configurations and inspect Unreal logs directly from Rider.
Watch out: Rider is a separate commercial IDE depending on your license; RiderLink should match the Rider/engine setup.

Adoption decision

High for C++ projects. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
