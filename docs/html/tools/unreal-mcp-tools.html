Unreal MCP Tools (this repository)

Our production-oriented extension layer for Blueprint inspection, graph mutation, validation and Codex workflows.

Why it helps

  • Safe Blueprint read/write operations
  • Transactions and compile policy
  • Structured project inspection
  • Codex-focused guardrails

Codex / MCP role

Primary custom toolset layer. Add project-specific tools here only when Epic does not already expose them.

Recommended workflow

  1. Install Plugin/UnrealMCPTools into the game project.
  2. Enable official Unreal MCP dependencies.
  3. Run environment checks.
  4. Inspect before mutating.
  5. Compile, validate, re-read, then explicitly save.
Watch out: Must be built with UHT/UBT in a real UE 5.8 editor target before being treated as verified.

Adoption decision

Must adopt. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
