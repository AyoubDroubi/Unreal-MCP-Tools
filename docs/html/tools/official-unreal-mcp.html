Official Unreal MCP

Epic's native MCP server and Toolset Registry bridge. This should be the primary AI transport layer for UE 5.8+.

Why it helps

  • Native Unreal Editor execution
  • AICallable tool discovery through Toolset Registry
  • Works with MCP-compatible agents such as Codex
  • Avoids direct binary asset hacking

Codex / MCP role

Foundation layer. Our plugin should extend it rather than create a parallel protocol server.

Recommended workflow

  1. Enable ModelContextProtocol and ToolsetRegistry plugins.
  2. Start the MCP server from Unreal Editor.
  3. Connect Codex using the generated MCP configuration.
  4. Prefer tool calls over UI automation when a native tool exists.
Watch out: Experimental API surface can change between engine versions; pin the supported Unreal version and verify tool discovery after upgrades.

Adoption decision

Must adopt. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
