Mass Entity / Mass Framework

Data-oriented entity framework for large numbers of agents/entities and scalable simulation.

Why it helps

  • High entity counts
  • Data-oriented performance
  • Mass AI/crowd use cases
  • UE 5.8 contains major framework improvements

Codex / MCP role

Specialized architecture; Codex should not introduce Mass unless project scale warrants it.

Recommended workflow

  1. Use only when actor-per-entity architecture becomes a measured bottleneck.
  2. Model fragments/processors intentionally.
  3. Prototype representative entity counts.
  4. Profile before and after.
Watch out: Higher conceptual complexity than Actors/Components; premature adoption can slow development.

Adoption decision

Specialized. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
