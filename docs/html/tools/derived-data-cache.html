Derived Data Cache (DDC)

Caches derived/cooked representations so shaders and assets do not rebuild unnecessarily.

Why it helps

  • Faster editor startup
  • Faster shader/content iteration
  • Shared team cache
  • CI speed

Codex / MCP role

Infrastructure guidance: never commit DDC; diagnose build slowness before changing game code.

Recommended workflow

  1. Use local DDC for every developer.
  2. Configure a shared cache for teams/build machines.
  3. Keep cache outside Git.
  4. Monitor misses when iteration becomes unexpectedly slow.
Watch out: DDC is disposable cache, not source-of-truth content.

Adoption decision

High for teams. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
