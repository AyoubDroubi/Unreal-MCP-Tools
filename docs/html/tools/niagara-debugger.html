Niagara Debugger

Live level-wide inspection and performance analysis for Niagara systems, emitters and parameters.

Why it helps

  • Find expensive effects
  • Watch systems/parameters
  • Performance overview
  • Faster VFX debugging than graph inspection alone

Codex / MCP role

Use debugger output as objective evidence before asking Codex to optimize Niagara content.

Recommended workflow

  1. Open Tools > Debug > Niagara Debugger.
  2. Reproduce the expensive/broken scene.
  3. Filter/watch target systems and parameters.
  4. Identify count/cost anomalies.
  5. Change the effect and remeasure.
Watch out: Optimize representative scenes; isolated editor previews can hide aggregate VFX cost.

Adoption decision

Must adopt for Niagara-heavy games. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
