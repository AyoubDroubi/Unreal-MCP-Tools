Unreal Insights

Unreal's trace analysis suite for CPU, frame timing, tasks, loading and subsystem performance.

Why it helps

  • Find real bottlenecks
  • Trace async/task behavior
  • Frame timing
  • Evidence-based optimization

Codex / MCP role

Provide trace findings to Codex so it optimizes measured hotspots instead of guessing.

Recommended workflow

  1. Capture a representative trace.
  2. Identify the expensive frame/thread/span.
  3. Form a specific hypothesis.
  4. Optimize one issue.
  5. Capture again and compare.
Watch out: Do not optimize from anecdotes; profile representative builds and scenarios.

Adoption decision

Must adopt. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
