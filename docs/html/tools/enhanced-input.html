Enhanced Input

Asset-based input actions, triggers, modifiers and mapping contexts for contextual/remappable controls.

Why it helps

  • Runtime remapping
  • Contextual input
  • Chorded/triggers/modifiers
  • Cleaner than monolithic input graphs

Codex / MCP role

Codex can create consistent input assets/handlers once corresponding MCP asset tools exist.

Recommended workflow

  1. Create Input Actions.
  2. Group bindings in Mapping Contexts.
  3. Add/remove contexts by player state.
  4. Keep gameplay actions separate from physical keys.
  5. Test keyboard/gamepad/device switching.
Watch out: Avoid binding gameplay logic directly to raw keys throughout Blueprints.

Adoption decision

Must adopt. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
