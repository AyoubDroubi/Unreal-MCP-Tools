Slate Inspector Toolset

Playwright-style automation for Unreal Editor Slate UI: snapshots, screenshots, clicks, typing, drag, wait and form filling.

Why it helps

  • Lets Codex operate editor UI when no native API exists
  • Stable widget refs
  • UI screenshots for verification
  • Useful for editor plugins and custom tools

Codex / MCP role

Fallback lane after native MCP/API tools. Excellent for UMG/editor workflow smoke tests.

Recommended workflow

  1. Observe the target window/panel.
  2. Snapshot the widget tree.
  3. Use refs for click/type/select/drag.
  4. Wait for expected UI state.
  5. Take a screenshot when visual evidence matters.
  6. Unobserve when done.
Watch out: Do not use UI automation when a deterministic native tool exists; UI labels and layouts are more fragile.

Adoption decision

Must adopt. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
