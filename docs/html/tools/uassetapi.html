UAssetAPI

Low-level .NET library for reading and writing Unreal assets outside the editor.

Why it helps

  • Offline inspection
  • Modding/tooling
  • JSON-like transformations
  • Useful for forensic or pipeline tasks when Unreal Editor is unavailable

Codex / MCP role

Fallback offline asset-inspection lane, not the normal production mutation path.

Recommended workflow

  1. Use primarily for inspection/extraction.
  2. Keep production Blueprint semantic writes inside Unreal Editor.
  3. Pin the Unreal asset version before parsing/writing.
  4. Validate any generated assets by opening them in Unreal.
Watch out: Direct binary asset writes bypass Unreal editor invariants and compilation; use with strict safeguards.
