BlueprintUE

Plugin/service workflow for sharing Blueprint graphs in a web-readable format.

Why it helps

  • Fast collaboration
  • Easy graph sharing
  • Good for bug reports and design review
  • Useful external representation

Codex / MCP role

Useful for sharing a graph snapshot with humans; not required for internal MCP editing.

Recommended workflow

  1. Use only for non-sensitive graphs.
  2. Export/share the smallest relevant graph.
  3. Keep source-of-truth in the Unreal project.
  4. Do not upload proprietary logic without approval.
Watch out: External service and documented plugin compatibility must be reviewed before project use.
