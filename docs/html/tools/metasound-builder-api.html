MetaSound Builder API

Blueprint/C++ API for procedurally creating and modifying MetaSound Sources/Patches and graph connections.

Why it helps

  • Automatable audio authoring
  • Can create assets from Editor Utility Blueprints
  • Runtime/in-memory generation
  • Excellent candidate for Codex-native audio tooling

Codex / MCP role

This is the preferred engine-native foundation for future MetaSound MCP tools instead of UI automation.

Recommended workflow

  1. Use the Builder subsystem for in-memory/runtime generation.
  2. Use the Editor subsystem for asset authoring.
  3. Wrap repetitive project patterns in deterministic helpers.
  4. Audition changes, then serialize explicitly.
  5. Verify documented unsupported graph features before relying on them.
Watch out: The API is Beta and has documented limitations; pin to UE 5.8 and smoke-test after engine upgrades.

Adoption decision

High for audio automation. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
