Scriptable Tools System

Blueprint-accessible Interactive Tools Framework for building custom viewport interaction tools and editor modes.

Why it helps

  • Custom placement/editing tools
  • Technical-art workflows
  • Viewport interaction beyond buttons
  • Reusable project-specific editor modes

Codex / MCP role

Useful when the optimal workflow needs a human-in-the-loop viewport tool rather than a hidden command.

Recommended workflow

  1. Enable Scriptable Tools Editor Mode.
  2. Create an editor-only Scriptable Tool Blueprint.
  3. Expose focused user interactions.
  4. Use transactions for asset/world mutations.
Watch out: This is for editor tooling, not runtime gameplay.

Adoption decision

Medium. Treat this page as a project decision guide; confirm engine version, license, team scale and project constraints before adoption.
