# Game Dev Toolbox

This catalog contains **91 separate guides** covering tools, repositories, Unreal systems and development methods that materially improve a Blueprint-heavy UE workflow.

Open `docs/html/index.html` in a browser for the visual catalog.

## Query from terminal

```bash
python scripts/game_dev_toolbox.py list
python scripts/game_dev_toolbox.py show official-unreal-mcp
python scripts/game_dev_toolbox.py recommend "multiplayer blueprint debugging"
```

## Adoption hierarchy

1. Unreal-native deterministic API/tool.
2. Official UE 5.8 MCP toolset.
3. Our `UnrealMCPTools` extension when Epic has no equivalent.
4. Mature external plugin/repository after version/license verification.
5. Slate UI automation for workflows with no native API.
6. Direct `.uasset` mutation only for specialized offline inspection/tooling.
